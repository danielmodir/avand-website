Avand Privacy Policy

Last updated: October 2026. This reflects the product's actual current state, not a finalized legal document for a complete product.

This website

Avand's marketing site (the page you're reading) has no forms, no tracking cookies, and no third-party analytics, and it doesn't collect any personal information from visitors. The only thing this site might ever receive from you is the app installer (APK) you knowingly choose to download.

The web preview

The web version opened from the "Try web preview" button is an interactive prototype that isn't connected to any real account or server yet. Anything you enter there (tasks, habits, events, profile settings) stays only in that browser tab's memory and is lost when you close or refresh the page — nothing is stored anywhere or sent to a server.

Once the real app connects to an account

The Avand app doesn't have a real account system yet. When that part is built, this page will be updated before that release goes public, and will state exactly what's stored (account email, profile info, calendar tasks/habits/events), what device info and technical logs are kept for debugging, and — if a third-party integration like Google Calendar sync is added later — exactly what data is shared with that service.

Until then, we make no claims about encryption or server-side storage, because no such server exists yet.

Account and data deletion

Since there's no real account system yet, there's nothing to delete server-side. In the web preview, clearing your browser's history/cache or closing the tab removes everything you entered.

Security

This site is served over HTTPS. No tracking code or third-party script is loaded.
