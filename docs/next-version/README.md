تاریخ بررسی: ۲۰۲۶-۱۱-۱۵، منطقهٔ زمانی Asia/Tehran. مبنای کد: `927f48a`. چک‌لیست پس از افزودن NV-03-07 اکنون ۱۱۳ ردیف دارد.

## قرارداد نگهداری

- مرجع وضعیت توسعه، `MASTER_CHECKLIST.md` است؛ وجود کد فعلی با تکمیل نیازمندی نسخهٔ جدید یکسان نیست.
- پس از هر تغییر: ردیف‌های مرتبط، تصمیم‌ها، نتیجهٔ تست و هر دو تاریخچهٔ این پوشه و `../CHANGES.md` به‌روز شوند.
- شناسه‌ها ثابت می‌مانند؛ نیازمندی تکراری به شناسهٔ اصلی ارجاع داده می‌شود، نه اینکه حذف یا دوباره پیاده‌سازی شود.
- `Approved` فقط با تأیید صریح مالک، همراه تاریخ و محدودهٔ تأیید ثبت شود. در این گزارش هیچ قابلیت تأییدشده‌ای ثبت نشده است.
- تغییرات روی لوکال و سپس شاخهٔ جداگانهٔ GitHub قابل بررسی‌اند. Workflow فعلی روی push به `master`، GitHub Pages را منتشر می‌کند؛ برای حفظ مرحلهٔ بررسی، این گزارش روی `master` ارسال نمی‌شود.
- تغییرات از قبل موجود در `.claude/launch.json`، فایل ثبت‌نشدهٔ `AGENTS.md` و `deploy/mcp-relay-worker.js` متعلق به این کار نیستند و در commit این بررسی وارد نمی‌شوند.

## مرز اعتبار گزارش

کد، مسیرهای API، مدل‌ها و Migrationها، کلاینت‌ها و تست‌های موجود بررسی شده‌اند. بررسی فایل‌ها با مشاهدهٔ وضعیت واقعی سرور یکسان نیست. به هاست اصلی، دیتابیس واقعی و حساب‌های خارجی متصل نشده‌ایم؛ ادعای تست عملی همهٔ صفحات، امنیت کامل، سلامت PHP روی هاست یا صحت اعلان روی گوشی واقعی نداریم. موارد اجراشده و اجرا‌نشده دقیقاً در `TEST_REPORT.md` ثبت شده‌اند.
