# تاریخچهٔ نسخهٔ بعد

## ۲۰۲۶-۱۱-۲۵ — آغاز اتصال Google Calendar

- دامنهٔ مصوب: فقط تقویم اصلی Google و فقط ایونت‌ها، با همگام‌سازی دوطرفه؛ حذف یک‌طرفه و تعارض هم‌زمان با تأیید کاربر حل می‌شوند.
- اتصال نخست، ایونت‌های موجود هر دو طرف را ادغام می‌کند؛ تکرارهای شمسی/قمریِ ناسازگار فقط در توجیبی می‌مانند.
- Workflow مستقل PHP برای lint و تست روی شاخهٔ توسعه افزوده شد. اتصال OAuth، داده و UI هنوز در این گام تغییر نکرده‌اند.
- گام بعدی: مجوز مستقل Calendar در PHP با state یک‌بارمصرف، PKCE، scope محدود owned-events، refresh token رمز‌شده و Migration افزایشی v29؛ هنوز موتور تبادل رویداد، رابط کاربری و کلاینت Google Cloud آماده نیستند.
- مقایسهٔ سه‌طرفهٔ بدون اثر جانبی برای تشخیص ویرایش یک‌طرفه، حذف نیازمند تأیید و تعارض ویرایش هم‌زمان افزوده شد؛ نوشتن به Google هنوز پیاده نشده است.
- نگاشت بدون اثر جانبی برای ایونت‌های تک‌نوبتی، بازهٔ تمام‌روز و زمان‌دار افزوده شد؛ پایان انحصاری Google، منطقهٔ زمانی تهران و لینک جلسه حفظ می‌شوند. تکرارهای همهٔ نوع‌ها تا آماده‌شدن نگاشت دقیق هنوز منتقل نمی‌شوند.

## ۲۰۲۶-۱۱-۲۵ — آماده‌سازی اتصال GitHub Pages به API

- روتر PHP برای Origin دقیق Pages و preflight درخواست‌های JSON/توکن آماده شد. API زنده هنوز پچ را ندارد و پیکربندی Pages عمداً آفلاین مانده است.
- ابزار کنترل پنل هاست در این نشست پاسخ نداد؛ PHP CLI و آزمون زندهٔ CORS پس از استقرار هنوز لازم‌اند.
