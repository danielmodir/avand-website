## ۲۰۲۶-۱۱-۱۷ — نمایش مستقل یک ایونت در دو میزکار

- Node 46/46، Django 91/91 و هشت حالت مرورگر موفق؛ دیتابیس واقعی، PHP CLI، گوشی و انتشار بررسی نشده‌اند.

- جلوگیری از backfill با cutoff هنگام ذخیرهٔ فعالیت؛ اصلاح بازبینی برای تأخیر بین تأیید یادآوری و ذخیره، و تغییر تاریخ/تکرار.
- UI، نگاشت Django، اعتبارسنجی PHP و Migration افزایشی planning 0009؛ هیچ Migration روی دادهٔ واقعی اجرا نشد.
- محدودیت‌های صف 400تایی، تغییر timezone گوشی بسته و نبود PHP CLI/گوشی در REMINDER_WINDOWS ثبت‌اند؛ وضعیت In Progress است.
