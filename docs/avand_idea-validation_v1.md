# آوند (Avand) — فاز ۱: اعتبارسنجی ایده (Idea Validation)

> وضعیت: بخش «بررسی رقبا» و «Value Proposition» انجام شد. بخش «مصاحبه با کاربران» موکول شد به مرحله‌ی تست.

---

## ۱. بررسی رقبا

| رقیب | نقطه‌قوت | ضعف نسبت به نیاز آوند |
|---|---|---|
| **Notion** | انعطاف‌پذیری کامل، Knowledge Base قوی | فیچر اختصاصی برای Habit/Fitness/AI coaching نداره؛ کاربر باید همه‌چیز رو خودش بسازه (barrier ورود بالا) |
| **Todoist** | مدیریت Task با زبان طبیعی (مثل «فردا»، «هر ۳ روز») | پوششی برای Habit یا Fitness نداره؛ کاربر مجبوره اپ دوم هم نصب کنه |
| **Habitica** | گیمیفیکیشن (RPG)، رایگان | تجربه‌ی کاربری قدیمی‌تر، بدون تایمر داخلی، پایین‌ترین رتبه‌ی فروشگاهی در بین رقبا |
| **Fabulous** | روتین‌های هدایت‌شده بر پایه‌ی علم رفتاری | Task و Fitness Tracking نداره |

**نتیجه‌ی مشترک:** هیچ‌کدوم از این چهار رقیب Task + Habit + Category تخصصی (مثل Trading/University) + Tool Store رو با هم پوشش نمی‌دن؛ هرکدوم فقط یه بعد از نیاز رو حل می‌کنن.

---

## ۲. Value Proposition پیشنهادی

> برخلاف Notion که باید همه‌چیز رو خودت بسازی، یا Habitica/Todoist که فقط یه بعد از زندگیت رو پوشش می‌دن، آوند هم ساختار آماده (Category/Tool) داره هم انعطاف کامل — با یه فروشگاه ابزار تخصصی که رقبا اصلاً ندارن.

---

## ۳. مصاحبه با کاربران — موکول به بعد

تصمیم گرفته شد فعلاً وارد این بخش نشیم؛ در مرحله‌ی تست (فاز ۸) دوباره بررسی می‌شه. یه اسکریپت مصاحبه‌ی ۵ سوالی هم آماده شده بود که در صورت نیاز قابل بازیابیه:

1. الان برای کارها/عادت‌هات از چه اپ یا روشی استفاده می‌کنی؟
2. بزرگ‌ترین مشکلی که با همون روش داری چیه؟
3. اگه یه چیزی توی اون اپ می‌تونستی عوض کنی، چی بود؟
4. تا حالا شده یه عادت یا چالش رو نصفه‌کاره ول کنی؟ چرا؟
5. اگه یه اپ بود که کارها، عادت‌ها و حوزه‌های خاص زندگیت رو با هم مدیریت می‌کرد، چه چیزی توش می‌خواستی؟
