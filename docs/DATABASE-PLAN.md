# طرح دیتابیس توجیبی — تصمیم‌های نهایی

> طرح اجرا شده: جدول‌ها مدل‌های جنگو در `backend/apps/<ماژول>/` هستن و راه‌اندازی MySQL در `database/`.
> جزئیات فنی در `backend/README.md` و `database/README.md`.
> این فایل فقط تصمیم‌های محصولی که طرح بر اساسش ساخته شد رو نگه می‌داره.

## تصمیم‌ها (۱۴۰۵/۰۷/۲۳ — 2026-10-15)

| موضوع | تصمیم |
|---|---|
| ساختار | هر میزکار/قابلیت یک **دیتابیس جدا** و یک پوشه‌ی جدا: core، planning، period، social، notifications |
| ورود | فعلاً ایمیل + گوگل؛ تلفن بعداً به‌عنوان provider جدید در `oauth_accounts` |
| تسک تکراری | هر روز جدا تیک می‌خوره (`task_occurrences`) |
| ریزتسک | خودش یک تسکه (`parent_id`)، فقط یک سطح، تکرار مستقل نداره |
| ویرایش مورد تکراری | «فقط همین روز / این و بعدی‌ها / همه» |
| رویداد | ساعت شروع/پایان اختیاری + یادآور «چند دقیقه قبل» |
| دسته‌بندی | فقط داخل میزکار برنامه‌ریزی |
| خاموش کردن میزکار | داده‌ها می‌مونن؛ دکمه‌ی جدا برای حذف داده‌ها |
| عکس | فعلاً روی سرور، حداکثر ۳ مگ، JPG/PNG/WebP، تبدیل به WebP؛ قابل انتقال به فضای ابری |
| پرداخت / فروشگاه | فعلاً ساخته نمی‌شه |
| اعلان | ماژول جدا، غیرفعال تا ساخت اپ |
| پریود | دیتابیس جدا، رمزنگاری با کلید جدا برای هر کاربر، کلید اصلی روی سرور |
| حذف حساب | ۳۰ روز فرصت برگشت |
| ادمین | نقش‌ها و دسترسی‌ها از الان (مدیر کل، ویرایشگر محتوا، ناظر) |
| آفلاین | پشتیبانی می‌شه (`version` / `updated_at` / `deleted_at`) |
| اضافه‌شده بعد از بررسی | منطقه‌ی زمانی، پذیرش حریم خصوصی/شرایط (نسخه‌دار)، وضعیت Onboarding، گزارش تخلف، صف ایمیل، نسخه‌های اپ اندروید، ثبت میزکار مناسبت‌ها |
| بک‌اند (۱۴۰۵/۰۷/۲۴) | جنگو + DRF به‌جای Express؛ دیتابیس جدید `toojibee_calendar` برای مناسبت‌ها و شروع رسمی ماه‌های قمری |
| ورود با گوگل در وب | ریدایرکت سمت سرور + کد یک‌بارمصرف؛ هیچ اسکریپت گوگلی در سایت لود نمی‌شه |
