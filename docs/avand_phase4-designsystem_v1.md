## ۱. رنگ‌ها (Colors)

پایه‌ی پالت رنگی از این منبع انتخاب شد: `#1B262C` `#0F4C75` `#3282B8` `#BBE1FA`

| نقش | Light Mode | Dark Mode | توضیح |
|---|---|---|---|
| Primary (اصلی) | `#3282B8` | `#3282B8` (احتمالاً با کمی روشن‌تر برای کنتراست بهتر روی پس‌زمینه‌ی تیره) | رنگ اصلی دکمه‌ها، لینک‌ها، تاکیدها |
| Secondary (ثانویه) | `#0F4C75` | `#0F4C75` | هدر، جزئیات ثانویه |
| پس‌زمینه‌ی اصلی (Background) | آبی خیلی روشن / کرمی، بر پایه‌ی `#BBE1FA` | `#1B262C` | پس‌زمینه‌ی صفحات |
| متن اصلی (Text Primary) | مشکی | سفید / خاکستری خیلی روشن | متن‌های اصلی |
| موفقیت (Success) | سبز نرم و مات (غیرجیغ) | نسخه‌ی تیره‌ی همون سبز | تیک، پیام موفقیت |
| خطا (Error) | قرمز نرم و مات | نسخه‌ی تیره‌ی همون قرمز | خطا، حذف |
| هشدار (Warning) | زرد نرم و مات | نسخه‌ی تیره‌ی همون زرد | هشدار، یادآوری مهم |

**Dark Mode:** از همون ابتدا (MVP طراحی) لازمه و باید بر پایه‌ی همین پالت ساخته بشه.
