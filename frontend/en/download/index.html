The Android app is the same Toojibee as the web app, with the same account. It opens without internet too, and your phone shows reminders on time, even when the app is closed; tick a task right from the notification, or have it remind you later. It also has four home-screen widgets: today's date, the month calendar, the planning desk (tick from it) and the period ring.

How to install

  1. Download the APK file using the button above.
  2. Open the downloaded file from your notifications or Downloads folder.
  3. If Android blocks the install, go to Settings → allow installs from this source for your browser or file manager, then try again.
  4. Confirm the install. Toojibee will appear in your app list like any other app.
