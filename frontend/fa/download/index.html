دانلود توجیبی برای اندروید

این نسخه‌ی اولیه (بتا) هست، مستقیماً از همین سایت دانلود می‌شه، نه از Google Play. ممکنه اندروید قبل از نصب هشدار «منبع ناشناس» نشون بده — طبیعیه.

دانلود APK

نسخه‌ی اندروید هنوز منتشر نشده. تا اون موقع، توجیبی رو از نسخه‌ی وب استفاده کن؛ روی گوشی هم کامل کار می‌کنه.

راهنمای نصب

  1. فایل APK رو با دکمه‌ی بالا دانلود کنید (بعد از انتشار).
  2. فایل دانلودشده رو از اعلان‌ها یا پوشه‌ی Downloads باز کنید.
  3. اگه اندروید نصب رو مسدود کرد، برید به تنظیمات ← اجازه‌ی نصب از این منبع برای مرورگر یا فایل‌منیجرتون، و دوباره امتحان کنید.
  4. نصب رو تأیید کنید. توجیبی مثل هر اپ دیگه‌ای تو لیست اپ‌هاتون ظاهر می‌شه.
