راهنمای نصب

  1. فایل APK رو با دکمه‌ی بالا دانلود کنید (بعد از انتشار).
  2. فایل دانلودشده رو از اعلان‌ها یا پوشه‌ی Downloads باز کنید.
  3. اگه اندروید نصب رو مسدود کرد، برید به تنظیمات ← اجازه‌ی نصب از این منبع برای مرورگر یا فایل‌منیجرتون، و دوباره امتحان کنید.
  4. نصب رو تأیید کنید. آوند مثل هر اپ دیگه‌ای تو لیست اپ‌هاتون ظاهر می‌شه.
